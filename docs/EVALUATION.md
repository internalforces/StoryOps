# 평가 설계와 결과

## 목적

연속성 검사가 “오류처럼 보이는 문장”을 많이 내는 것이 아니라, 관련 정본 설정을 실제로 찾고 충돌과 정상 문장을 구분하는지 검증한다.

## 데이터셋

- 의도적 충돌 5건: 시간 규칙, 인물 외형, 공간 구조, 생물 능력, 도구 성질
- 정상 문장 5건: 동일 설정을 지키는 의미 대응 문장
- 모든 문장과 설정은 공개 데모용 합성 데이터이며 실제 원고를 포함하지 않는다.

## 측정 항목

| 지표 | 현재 결과 | 의미 |
|---|---:|---|
| 정확도 | 100% | 10개 문장 중 올바르게 분류한 비율 |
| 정밀도 | 100% | 충돌로 잡은 문장 중 실제 충돌 비율 |
| 재현율 | 100% | 의도한 충돌 중 찾아낸 비율 |
| Hit@5 | 100% | 정답 설정이 검색 상위 5개에 포함된 비율 |
| MRR | 1.00 | 정답 설정의 평균 역순위 |
| API 비용 | $0 | 브라우저 내 결정론적 실행 |

실행 시간은 기기와 브라우저에 따라 달라지며 평가 화면에서 매번 실측한다.

## 발견한 실패와 수정

초기 회귀 테스트에서 “기억나침반은 언제나 북쪽을 향했다”를 찾지 못했다. 설정에 등록된 표현이 “항상 북쪽”뿐이어서 의미가 같은 부사 변형을 놓쳤다. “언제나 북쪽”, “북쪽을 향”을 충돌 표현에 추가해 회귀셋을 통과시켰다.

이 사례는 단순 표현 사전의 한계를 드러낸다. 프로덕션에서는 임베딩 검색, 시점·화자 메타데이터, LLM 판정의 조합이 필요하다.

## 알려진 실패 유형

1. 설정에 없는 동의어와 비유는 누락될 수 있다.
2. 과거와 현재의 설정 변화가 구분되지 않으면 정상 변화를 충돌로 볼 수 있다.
3. 거짓말, 꿈, 회상, 불확실한 화자의 문장은 장면 메타데이터 없이는 판별하기 어렵다.
4. 동일 인물이나 장소의 별칭이 연결되지 않으면 검색 순위가 낮아질 수 있다.
