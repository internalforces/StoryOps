# 1~2분 시연 가이드

현재 시연 자료는 `docs/demo/01-overview.png`부터 `06-evaluation.png`까지의 최신 화면 캡처와 [`demo-narration.txt`](demo/demo-narration.txt)로 구성됩니다.

## 장면 구성

| 시간 | 화면 | 설명 |
|---|---|---|
| 0:00–0:12 | 운영 현황 | **120화 규모 데모**를 불러와 120화·240버전·경고 0건 확인 |
| 0:12–0:24 | 작품과 회차 | CRUD, 초안/정본, 공개 범위, 안정 ID |
| 0:24–0:36 | 인물과 설정 | 정본·별칭·직접 충돌·의미 패턴과 근거 회차 연결 |
| 0:36–0:48 | 연속성 검사 | 별칭·간접 표현 검색, 충돌·문맥 필요 후보 분리 |
| 0:48–1:00 | 사용자 검수 | 오류 승인과 오탐 처리, 근거 확인 |
| 1:00–1:12 | 평가 리포트 | 같은 70건에서 v1 14건 → v2 70건, 문맥 식별 0건 → 30건 비교 |

## 재생성

화면 캡처를 `docs/demo/01-overview.png`부터 `06-evaluation.png`까지 교체한 뒤, 저장소의 동일한 내레이션으로 영상을 다시 생성할 수 있다. 영상은 1080p H.264/AAC로 인코딩되어 GitHub와 일반 브라우저에서 바로 재생된다.
